# Independent matrix convergence audit

This harness loads each accepted canonical save through the release's normal validator, then simulates the same geometry, train and operations at half the stored integration timestep. It records every result in JSONL and never changes accepted rides or generation parameters.

Peak speed must differ by less than1%. Signed vertical extrema, peak lateral/longitudinal force, positive10-second exposure and the assessed vertical force-rate peak must differ by less than2%. Relative differences use the fine run as denominator, with a1-unit floor for near-zero quantities (forces therefore have a0.02g absolute tolerance below1g). Both runs must complete, the fine simulation must be numerically valid, and all selected record/force gates must still pass at the fine step. Duration is reported separately. Unassessed lateral/longitudinal rate limits are not silently introduced by this audit.

The list must contain every accepted source save from the frozen matrix exactly once, excluding copied inspection bundles. Record the tested core source/executable hashes and input-save hashes alongside results. This tool supplies acceptance evidence; a failed result is not permission to weaken selected record targets or force gates. It does not establish convergence under arbitrary other train/target configurations, raw-reference calibration, structural validity or Unreal presentation performance.

Independent review hardened evidence identity: the complete coarse report must exactly equal the hash-verified frozen matrix replay, excluding only the measured subprocess-independent wall-clock generationSeconds field. The final matrix audit also requires per-front/middle/rear signed extrema and1s/10s rolling means for all three axes, each seat exposure and every assessed component rate to meet2% tolerance. A stable global maximum cannot hide a changed rear-seat peak. Missing seat statistics makes the final matrix audit fail. Original baseline smoke fixtures only establish global harness behavior because that release predates per-seat summary statistics. All-null metric failures remain reportable as null rather than aborting aggregation.
