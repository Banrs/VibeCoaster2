# VibeCoaster native game

**0.8.0-immelmann.1 / COASTER5**: the 0.8.0 baseline with the improved complete Immelmann and low return. User review is pending. [Current issues](NEXT_CHAT.md).

Open [Play VibeCoaster.cmd](Play%20VibeCoaster.cmd). The existing installation keeps its old folder name so shortcuts still work. Keep its `Engine` and `VibeCoaster` folders beside the executable.

- Choose PHYSICS-PROOF, terrain and seed. Enter generates; Space starts the ride.
- Up/Down selects settings; Left/Right changes them. Tab toggles setup.
- 1/2/3 selects front/middle/rear seats; M shows overview; R restarts.
- C compares; T shows telemetry; F5 saves; F9 loads; Alt+F4 exits.

Saves require their exact numerical version. Old saves remain preserved and require their corresponding older application. ALL RECORDS requires eligible authentic reference recordings.
