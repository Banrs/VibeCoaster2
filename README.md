# VibeCoaster

Single-player Unreal Engine 5 coaster game with an independent C++ core in [native](native/).

Current source: **0.8.0-immelmann.1 / COASTER5**. Restored the released 0.8.0 generator, simulation and rendering, with the improved complete Immelmann and its low return. The old elevated Immelmann/dive-loop connection is replaced by that return.

Open [Play VibeCoaster.cmd](native/Play%20VibeCoaster.cmd) to use the existing local installation. [Controls](native/README.md) · [Build instructions](native/tools/BUILDING.md) · [Current issues](native/NEXT_CHAT.md).

The last published unmodified 0.8.0 preview remains available in [GitHub releases](https://github.com/Banrs/VibeCoaster2/releases/tag/native-v0.8.0-flow.1). It does not contain the retained Immelmann integration.
